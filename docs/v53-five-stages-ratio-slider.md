# v53 5단계 루틴 · 시간 비율 슬라이더 · 알림카드/워치 (Figma 02 · ③ 운동 진행, ⑤ 앱 설정)

## 5단계
준비운동(0) → 유산소 ①(1) → 근력운동(2) → 유산소 ②(3) → 스트레칭(4). 인덱스 0~2는 기존과 같아 근력 기록/세트 저장은 영향이 없다.
- 스냅샷 JSON: `phases`(유산소 ①), `phases3`(유산소 ②), `phases4`(스트레칭). 키는 `phasesKeyForStage()` 한 곳에서 정한다.
- 마지막 단계는 `LAST_STAGE`(= 4). 마지막 단계의 다음 = 운동 종료 확인.
- 기록(`StageLog`)은 0..4를 저장한다. 이전 빌드의 3번 기록은 "유산소 ② + 스트레칭" 합산이었으므로 과거 날짜에는 "유산소 ②"로만 표시된다(기록 삭제/이동 없음).
- 진행 중이던 세션을 업그레이드하면 3번 단계의 경과 시간이 새 유산소 ② 길이를 넘으면 남은 시간 0으로 보정된다.

## 시간 비율 (설정)
- 슬라이더 하나에 손잡이 둘: ① 유산소 / ② 유산소 / 근력을 각각 5분 단위로 설정. 준비 5 + 스트레칭 5는 고정, 나머지 50분을 나눈다.
- 제한: 유산소 각 5분 이상, 근력 10분 이상. 운동 시작 후에는 변경 불가(스낵바 안내, 슬라이더 원위치).
- 업그레이드: 예전 "유산소 합계" 설정은 앞 구간 = 합계의 절반(5분 단위 반올림), 나머지 = 뒤 구간으로 변환한다.

## 단계 목록 (Figma 08)
- 헤더: 숫자 없는 알약 칩 + 상태(완료/진행 중/예정) + 펼침 아이콘. 근력은 "근력운동 · 하체/상체".
- 유산소/스트레칭 진행 중: 구간 행(48dp) = 완료 체크 / 진행 링(재생 중에만 회전, 시스템 애니메이션 끔 설정 존중) / 예정 원 + mm:ss, 현재 구간 RPE 칩, 남은 시간, 구간 진행 막대, "다음 · 구간".
- 구간 행을 눌러 이동하는 동작은 만들지 않았다(단계 이동은 이전/다음 단계 버튼만).

## 알림카드 · 워치
- 알림카드: 단계 칩/라운드가 5단계("n/5 단계")와 스트레칭 구간을 표시한다. 디자인 변경 없음(Figma에 새 알림 시안 없음).
- 워치(v47): 라벨 "n/5", 진행률 단계×20%, 유산소 ②/스트레칭 구간 표시, 마지막 단계 버튼 "운동 완료". 새 워치는 0~4, 이전 워치는 0~3으로 읽는다.

## 미검증
갤럭시 실기기(회전 링, 슬라이더 드래그, 알림카드), Galaxy Watch4 실기기 동작.
