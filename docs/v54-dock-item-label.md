# v54 · 하단 도크 항목명과 근력운동 시간 표시

Figma(02 폰 · UX 흐름)와 맞춘 변경이다. 화면 캡처는 CI의 `move60-smoke-evidence`에서 확인한다.

## 문구 규칙
- 도크 윗줄: `대분류 · 현재 항목` (예: `준비운동 · 전신 관절 가동성`, `근력운동 · 레그프레스`). "n/5 단계"는 쓰지 않는다.
- 도크 아랫줄: `남은시간 mm:ss · 전체시간 mm:ss / 60:00`. 남은시간은 현재 항목의 남은 시간이며 큰 타이머와 같은 값이다.
- 근력운동은 기구별 이동·세트 시간이 달라 남은시간을 배정하지 않는다. 도크는 `전체시간 mm:ss / 60:00`만 보여준다.
- 단계 칩 글자는 16sp 굵게, 가로 여백 12dp.

## 데이터/동작
- 준비운동 항목은 `workouts.json`의 설명("… 2분")에서 항목별 시간을 읽어 타이머 항목(`phases0`)이 된다.
  항목 시간 합이 준비운동 시간과 다르면 항목 타이머 없이 단계 시간으로 동작한다(기존 방식).
- 알림 카드·위젯(큰 크기 포함): 근력운동 단계는 카운트다운 대신 `전체시간`이 올라간다. 다른 단계는 현재 항목 남은 시간이다.
- 워치: 준비운동도 구간 표시를 쓰고, 근력 단계의 앰비언트 문구는 `전체 약 N분`이다.

## 미확인
- 실기기(폰/워치) 확인은 하지 않았다. 알림 카드의 삼성 기본 알림 안 표시 문제는 이 변경에 포함되지 않는다.
