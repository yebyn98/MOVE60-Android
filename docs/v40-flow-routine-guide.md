# v40 — 홈↔상세 흐름, 유산소-근력-유산소 루틴, 동작 가이드

- **상세 화면 헤더**: 기존 "MOVE60" 앱 바를 제거하고 `←` 뒤로가기(48dp, tag `detail_back`) + 제목 "오늘의 운동"(tag `detail_title`)을 둔다. 알림에서 상세가 task root로 열린 경우 `leaveToOverview()`가 Compose 홈을 열고 종료한다.
- **루틴**: 준비운동 → 유산소 ① → 근력운동 → 유산소 ② · 마무리(유산소 정리 + 스트레칭). 유산소 총 시간(설정의 시간 배분)은 그대로이며 앞/뒤를 5분 단위로 나눈다. 합계는 항상 60분.
  - 단계 인덱스(0–3)와 기록 키는 유지되어 기존 운동 기록·세트 기록과 호환된다.
  - 스냅샷에 `phases3`(2번째 유산소 + 스트레칭 구간)이 추가되고, 각 구간에 `kind`가 포함된다. 워치는 단계 1·3에서 구간 정보를 표시한다.
- **진동**: 구간/단계 전환마다 알람 용도 속성의 3회 진동(최대 진폭). 실기기 확인 필요.
- **팝업**: `Move60AlertDialog`와 Compose `AlertDialog`(`DialogDim`)가 뒤 화면을 0.72로 딤 처리한다.
- **버튼**: 하단 독/휴식 버튼은 고정 높이 대신 `wrap_content` + 최소 48/52dp로 두 줄 텍스트가 잘리지 않는다.
- **동작 가이드**: `assets/exercise/<id>_0.jpg`, `_1.jpg` 2장을 3.2초 주기로 교차 페이드(`ExerciseGuide`). 출처는 `docs/exercise-images-sources.md`(Free Exercise DB, Unlicense). 이미지가 없는 6개 운동은 기존 선 그림을 대체 화면으로 사용한다.
