# 기록 정정 (정책 6, P-22·P-23) — 1차

## 구현한 것
- 수정 주체는 기록 소유자 본인, 기간 제한 없음. 경로: 기록(11) → 날짜별 기록(26) → 세션 상세(27) → "실제 운동 기록 수정" → "수정 이력 보기".
- **수정 가능한 값: 완료한 세트의 중량(kg)·반복 횟수.** 세션에 실제로 저장된 세트만 대상이며, 정정이 세트를 새로 만들지 않는다.
- 원본(`session_sets`·구간·분할·세션 행)은 **변경·삭제하지 않는다.** 정정은 추가 전용 `session_adjustments`에 `이전 값 · 새 값 · 수정 시각`으로 쌓이고, 화면은 원본 위에 **최신 정정값**을 덮어 보여주며 원본을 함께 표시한다("1세트 수정됨 · 원본 40kg × 12회").
- 저장은 **전부 또는 전무**: 값 하나라도 잘못되었거나 없는 세트·중복이 있으면 아무것도 저장하지 않는다. 저장이 성공하기 전에는 기존 기록을 그대로 보여준다(성공 후에만 다시 불러옴).
- 값 범위는 실시간 입력과 같다(중량 0~500, 횟수 1~100). 비우기·`1e2`·`NaN`·음수는 거부. 현재 값과 같으면 아무것도 쓰지 않는다.
- 정정은 활성시간·도전 인정에 영향을 주지 않으므로 **종료된 도전의 최종 스냅샷은 구조적으로 불변**이다(JVM 테스트로 확인).
- 확정 문구: "실제 운동 기록 수정" / "기록을 수정하면 이전 값과 수정 내역이 보존돼요." / "수정 이력 보기" / [취소] [수정 저장].

## 구현하지 못한 것과 이유
| 정책의 수정 가능 항목 | 상태 |
|---|---|
| RPE | **v2에 저장된 값이 없음**(세션 화면에 RPE 입력이 없다). 없는 값을 만들지 않으므로 수정 대상 아님 |
| 유산소 기구 실측값, 실제 강도 구간 입력값 | 세그먼트에 저장되는 값이 아직 없음(`docs/v61` 후 별도 기능) |
| v58(SharedPreferences) 세트 | 세션 행이 아니라 정정 이력을 걸 수 없음. 원본 그대로 두고 수정 불가로 표시 |
| 수정 중 화면 회전 | 대화상자에 입력한 값은 회전 시 초기화됨(저장된 기록에는 영향 없음) |
