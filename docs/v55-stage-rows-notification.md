# v55 — 예정·완료 단계 행, 알림 정리

- 원인: 진행 중이 아닌 단계는 v48부터 별도 텍스트 미리보기(`take(4)` + 안내 문구)로 그려졌고, 진행 단계만 구조화 행이었음. 테스트/검증 스크립트는 문자열 존재만 확인해 레이아웃 차이를 잡지 못했음.
- 변경: `buildStageRows()`가 예정/완료 단계를 진행 단계와 같은 행(아이콘·이름·시간 또는 세트·횟수)으로 표시. 입력 컨트롤 없음(읽기 전용), 종목 수 제한 없음.
- 알림: `n/N 구간` 배지 삭제. RPE가 없는 구간(준비운동·스트레칭)은 RPE 칩 숨김.
