## 1. 칼로리
- 숨긴 곳(문구 삭제, 데이터·계산 코드는 그대로): 이전 홈 dock "오늘 누적 … kcal · 추정", "워치 측정 … kcal · 기초대사 포함", 이전 결과 화면의 세션 합계와 단계별 "약 N kcal", 오늘 탭 "오늘 누적", 달력 일별 상세 "약 N kcal", 달력 단계 상세 "약 N kcal".
- 이전 홈의 kcal 뷰는 유지하되 항상 GONE이고 텍스트를 받지 않는다(`0 kcal` 대체 표시 없음).
- 보존: `EnergyLedger`, `WatchKcal` 저장값, DB `daily_workouts.estimatedKcal`은 변경·삭제하지 않았다.
- 배너: `KcalNotice` — 기존 이용자(v58 기록 또는 저장 세션이 있는 사용자)에게만, 기록 화면(달력) 첫 진입 시 1회, 비차단(확인 버튼, 뒤 화면 사용 가능). 표시되는 순간 "본 것"으로 저장한다. 조회에 실패하면 표시하지 않는다.
  - **배너 문구는 제가 작성했고 PO 승인 전이다**: 제목 "칼로리 표시를 더 이상 제공하지 않아요", 본문 "이전 운동 기록은 그대로 보존돼요."
- 검증 스크립트(`verify-compose-architecture.py`, `verify-design-tokens.py`)는 옛 문구가 **있어야** 통과하던 것을 kcal 문구가 **없어야** 통과하도록 반대로 바꿨다(변조 시험으로 위반 검출을 확인).
- **확인 필요(범위 밖으로 두었다)**: ① Wear 화면(`WearHealthActivity`, 타일, 워치 알림)의 kcal 표시 ② 설정의 "칼로리 계산 체중" 입력 항목(칼로리를 표시하지 않으므로 용도가 없어진다. 제거 여부는 PO가 결정) ③ 위젯·알림에 kcal이 있는지(코드상 문자열은 찾지 못했다).

## 2~3. 헬스장
- 이름은 필수(앞뒤 공백 제거 후 1~20자), 중복 불가, **등록한 헬스장은 이름 수정 가능**(`SpaceService.rename`). 집 공간은 이름이 고정이라 수정 대상이 아니다. 수정은 보유 기구·기본 공간 지정·기록에 영향을 주지 않는다.
- 운동공간(`workout_spaces`)과 기구(`space_equipment`)가 분리되어 있어 향후 지점 정보를 별도 테이블로 연결할 수 있다. 추측성 컬럼·테이블은 만들지 않았다.
- 외부 검색·자동완성·위치 기반 검색, 주소 입력은 구현하지 않았다.

## 7. 설정과 출시 요건
- 설정 화면은 변경하지 않았다.
- **코드 확인 결과(PO가 요청한 "현재 알림 기본값")**
  - 앱 내 소리(구간 전환 톤): 기본 **켜짐**(`preferences.sound` 기본값 true).
  - "운동 진행 · 잠금화면 타이머" 채널: 중요도 DEFAULT, **소리 없음, 진동 없음, 잠금화면 공개 범위 PUBLIC**.
  - "세트 휴식 완료" 채널: 진동 켜짐, 소리 없음.
  - "운동 구간 전환" 채널: 중요도 DEFAULT, 잠금화면 PUBLIC.
  - 알림 본문(`setVisibility(PUBLIC)`)도 PUBLIC이다. PO 권장(잠금화면 상세 공개 기본 OFF)과 **현재 동작이 다르다.** 결정 7은 기존 알림 동작 유지이므로 바꾸지 않았다. **P0 확인 필요: 잠금화면에 운동 내용이 공개되는 현재 동작을 출시 전에 허용할지.**
- **출시 요건(미충족)**: 앱 안에 개인정보처리방침 링크와 오픈소스 고지가 **없다**(코드에서 찾지 못했다). 유효한 처리방침 URL을 확보해 앱·Play Console에 연결하고, 사용 라이브러리의 고지 의무를 확인해 앱 내 목록으로 제공해야 하며 미충족 시 출시하지 않는다. **P0.**

## 8. 동작 안내
- 현재 상태: 운동 35개 중 **29개**에 라이선스 이미지 2장(`docs/exercise-images-sources.md`에 출처)이 있다. 나머지 **6개**(버드독, 벽 푸시업, 저항 밴드 로우, 클램셸, 힐 슬라이드, 스탠딩 니 리프트)는 `ExerciseGuide`가 **코드로 그린 도식(`ExerciseDiagram`)으로 대체 표시**한다.
- **확인 필요(P1)**: 이 도식이 "권리가 확인된 자체 제작 콘텐츠"에 해당하는지, 그리고 각 운동의 주의사항(`caution` 필드)이 "검수된" 것인지 기록이 없다. 해당하지 않으면 6개 운동은 도식 대신 빈 상태("동작 안내를 준비하고 있어요")를 보여야 한다. PO 확인 후 바꿀 수 있게 작은 변경으로 준비 가능하다.
- 기존 이미지와 승인된 동작은 변경하지 않았다. 콘텐츠가 없어도 운동 수행·기록은 그대로 동작한다.
- 네이티브 상세 화면은 Compose로 이전되지 않았으므로 이번에 건드리지 않았다.

## 9. 추천 루틴
- 현재 앱에는 추천 기능이 **없다.** 보유 기구와 목적은 저장만 되고 어디에도 반영되지 않는다.
- 그래서 "추천·직접 구성에 적용돼요" 문구는 **없는 기능을 있는 것처럼 보이게 하므로 바꿨다**: "공간별로 실제 이용할 기구를 등록해요.", "이 공간에서 이용할 보유 기구를 관리해요.", 최초 설정의 "선택 전에는 운동을 시작할 수 없어요."
