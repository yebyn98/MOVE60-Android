# v58 — 최신 피그마와 코드 차이 정리

## 원인
v55~v57은 사용자 메시지에 언급된 화면과 피그마 프레임 08만 확인하고 진행했다. 피그마 전체(홈·진행 03~14·위젯·알림·워치)를 매번 다시 읽고
코드와 대조하지 않았고, `verify-*.py`는 문자열 존재 여부만 검사해 레이아웃/문구 어긋남을 잡지 못했다.

## 차이와 조치
| 영역 | 피그마 | 이전 코드 | v58 |
| --- | --- | --- | --- |
| 홈 도크/카드 | "단계 n/5", 세트 카운트 없음. 도크 "대분류 · 항목". 시작 전엔 시작 버튼만 | "· 1/5 단계", "근력 세트 0/10 · 단계 1/5", 이전/다음 노출 | 제거, 도크 `itemName`, 시작 전 버튼 1개, 번호 원형 행 |
| 유산소 구간명 | "조금 빠른 페이스" | "1/2회차 · …" | 접두 제거(위젯·알림·폰·워치 공통) |
| 초과 시간 | 남은 시간이 0이면 | 알림이 매초 재게시되어 -00:01↔00:00 | 폰/도크/알림/위젯/워치 "+mm:ss"(카운트업) |
| 알림 | 시스템 프레임 없는 단독 카드 | 시스템 프레임 안에 자체 카드(카드 속 카드), 헤더 시계 중복 | 자체 배경·패딩·중첩 박스 제거, 높이 축소, 헤더 chronometer 제거 |
| 항목 이동 | 03·05~07 행 목록 | 유산소 행 탭 불가, 근력 행 목록 없음 | 진행 중 단계의 행 탭 → 해당 항목으로 이동(누적 시간 유지) |
| 워치 | 인트로 4프레임(로고 → 대기) | 시스템 런치 화면(녹색 + 아이콘)이 먼저 표시 | 런치 화면을 검정+투명 아이콘으로 교체 |
| 워치 완료 | W-05 "종료" (구버전) | "종료" | "새 운동"(폰의 새 운동과 같은 동작) — 피그마 W-05 갱신 필요 |
