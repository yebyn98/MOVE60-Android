## 1번 상세 (변경 범위)
- 파일: `WorkoutService.kt`(레거시 타이머: 진행·구간 전환·휴식 완료), `RoutiveSessionService.kt`(ROUTIVE 진행), `WorkoutDisplayService.kt`·`HeartRateService.kt`(Wear).
- 잠금화면에는 운동 종목·단계·남은 시간·심박·기록이 나오지 않는다. 알림을 누르면 앱이 열리고, 위젯형 사용자 지정 뷰는 잠금 해제 후에만 보인다.
- **채널 교체의 영향:** 기존 채널에서 사용자가 바꾼 소리·중요도 설정은 새 채널에 이어지지 않는다(채널 설정은 사용자가 가진 것이라 앱이 옮길 수 없다). 진단 화면은 새 채널 ID를 가리킨다.
- **미확인:** Android 버전별(8~15) 실제 잠금화면 표시, "민감한 알림 숨기기" 시스템 설정과의 상호작용, 타이머·기록 유지(알림은 표시 속성만 바꿨고 서비스 로직은 건드리지 않음). 모두 실기기 확인 대상이다.
- **결정 필요:** Wear의 Ongoing Activity는 워치 페이스에 단계 이름(예: "근력 · 운동 중")을 보인다. 이것은 폰 잠금화면 알림이 아니라 워치 UI 기능이라 **바꾸지 않았다.** 워치 페이스에도 숨길지 PO 결정이 필요하다.

## 5-1 상세 (Wear kcal)
- 표시 영역 조사: 타일(`WorkoutTileService`) — 제거함. 건강 화면의 칼로리 측정 설정 칩 — 위 처리. 운동 중 화면·완료 화면·알림·`WatchWorkoutState`의 `estimatedKcal` 필드는 화면에 표시하는 코드가 없다(필드는 직렬화 호환을 위해 유지).
- 칼로리 측정 자체(`WatchExerciseCalories`)는 이미 켠 사용자에 한해 계속 동작하며 폰으로 값을 보낸다. 표시는 없다. 이것을 아예 중단할지는 PO 결정 사항이다.
- 보존: `WatchKcal` 저장값, `EnergyLedger`, DB `daily_workouts.estimatedKcal`은 변경하지 않았다.

## 5-2 상세 (체중 사용처)
- `calorie_weight_kg`는 `EnergyLedger`(kcal 계산)에서만 쓰인다. 다른 승인 기능의 사용처는 찾지 못했다.
- **주의:** 사용자가 체중을 입력한 적이 없으면 코드가 기본값 63kg로 내부 계산한다. 표시하지 않으므로 사용자에게 보이지 않지만, kcal 정책 확정 시 이 기본값 사용 여부를 정해야 한다.
