# v56 — 근력 칼로리: 체크한 세트 기준

- 문제: 근력 단계에서 타이머가 도는 시간만으로 3.5 MET가 누적되어, 아무것도 하지 않아도 kcal가 올랐음.
- 변경: 근력 에너지는 체크한 세트만 계산(세트당 작업 시간 = 횟수 × 3초, 강도는 RPE로 구분 + 세트당 최대 40초 휴식 1.5 MET). 세트를 체크하지 않으면 0.
- 유산소: 센서 없이는 실제 페달링을 구분할 수 없어 계획 강도(RPE) 기반 추정 유지. 화면 표기는 "추정".
- 이전 기록 보존: 과거 일자의 저장 기록(legacy_met_seconds 등)은 건드리지 않음.
- 한계: 모든 값은 MET 기반 추정이며 측정값이 아님. 정밀 측정은 워치 심박/운동 칼로리 연동(별도 단계, 사용자 동의 필요).
