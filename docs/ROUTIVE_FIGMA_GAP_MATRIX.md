## 정책 일치 / Figma 또는 후속 작업 필요 사항

1. **출시 앱은 ROUTIVE:** 저장소/패키지 `MOVE60` 명칭은 기존 설치·업그레이드 연속성을 위해 유지될 수 있다. 사용자 표시명/스토어 메타데이터 전환은 실제 설치 검증과 함께 별도 확인한다. 패키지를 임의 변경하지 않는다.
2. **운동 시간 60분 강제 금지:** 도메인은 계획 시간이 미정(`null`)인 경우를 지원하고, 운동시간 실측과 계획을 분리한다.
3. **도전 시작일:** 생성일 고정(확정 정책). Figma 시작일 입력 필드가 남아 있으면 삭제/정리 대상.
4. **칼로리:** 폰·Wear 표시 비노출, 원본 DB와 저장값 불변. 기존 사용자에게 기록 탭 진입 첫 1회 승인 문구 배너. 화면 시안의 kcal 수치·필드는 삭제/비노출해야 한다.
5. **운동 공간:** 헬스장 외부 API 검색·주소/위치 검색은 MVP에서 구현하지 않는다. 직접 이름 등록과 보유 기구 저장만 확정되어 있다.
6. **마일스톤:** 첫 운동·누적 20일·첫 도전 완료, 데이터 조회 실패와 미달성 구분. LV 배지 미구현.
7. **가이드 콘텐츠:** 사용권과 동작·주의사항 검수 기록이 없는 35종 안내는 현재 모두 비노출. 실제 검수 전 시안의 사진·문구를 앱 화면 근거로 사용하지 않는다.
8. **기구 기반 추천:** 모든 35개 매핑 행은 승인 전이므로 개발 적용 금지. 운동 목적도 추천 로직에 아직 반영하지 않음.
9. **Wear 연결 상태:** 실제 기기 연결 검증 전 임의의 '연결됨' 상태를 표시하지 않는다. 워치 페이스의 단계 이름 노출은 현재 유지하는 정책.
10. **앱 설정:** 알림의 추가 토글·소리/진동 분리 등 미승인 항목은 임의 추가하지 않는다. 민감한 운동 정보 잠금화면 공개 기본 OFF.

## 테스트 증거 / 출시 블로커

- 통합 PR #57: 충돌 없이 PR #49 개발 브랜치에 병합; 당시 JVM 313개·Android 에뮬레이터 96개(3회) 성공 **보고**.
- CI: PR #49의 최신 커밋에서 각 테스트 실행 결과는 GitHub Actions에서 **별도 확인**한다. 과거 CI 성공을 최신 상태의 성공으로 간주하지 않는다.
- DB: Room v1→v6(현재 DB 버전 6) 업그레이드 계측 테스트가 있으며 최종 버전 검증 범위를 코드에서 보완함. 실제 v58 기록을 가진 휴대폰에서의 덮어 설치는 미검증.
- Wear: 에뮬레이터 CI와 Galaxy Watch4 실기기 시험은 별도이며, 심박·연결 끊김·앰비언트·타일·백그라운드는 실제 기기 점검 필요.
- 공개 배포: 개인정보처리방침 HTTPS URL이 비어 있다. 공개 배포 작업의 `verify-release-legal.py` 차단 검사와 해당 검사 존재 여부를 검증하는 CI 규칙을 추가했다. **URL의 실제 유효성·내용 적법성과 전이 의존성 OSS 고지 검토는 별도 미완료**.
- 앱 버전 및 출시 QA: 휴대폰 v58 / 워치 v52 코드를 그대로 사용하며, 스토어/공개 배포 전 버전 증가·기존 설치본 업그레이드 검증이 필요.
- 추적 이슈: [#58 — v58→v2 데이터·실기기·출시 게이트 QA](https://github.com/yebyn98/MOVE60-Android/issues/58). main 최종 통합 후보: [#49](https://github.com/yebyn98/MOVE60-Android/pull/49).
