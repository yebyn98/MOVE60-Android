## 정책 일치 / Figma 또는 후속 작업 필요 사항

1. **출시 앱은 ROUTIVE:** 저장소/패키지 `MOVE60` 명칭은 기존 설치·업그레이드 연속성을 위해 유지될 수 있다. 사용자 표시명/스토어 메타데이터 전환은 실제 설치 검증과 함께 별도 확인한다. 패키지를 임의 변경하지 않는다.
2. **운동 시간 60분 강제 금지:** 도메인은 계획 시간이 미정(`null`)인 경우를 지원하고, 운동시간 실측과 계획을 분리한다.
3. **도전 시작일:** 생성일 고정(확정 정책 v62). Figma FINAL/30의 시작일은 읽기 전용 표시만 허용하고, 숨겨진 이전 날짜 선택 팝업도 삭제해야 한다. 별도 '설정 확인' 정보 카드가 필요하다는 정책은 없다.
4. **칼로리:** 폰·Wear 표시 비노출, 원본 DB와 저장값 불변. 기존 사용자에게 기록 탭 진입 첫 1회 승인 문구 배너. 화면 시안의 kcal 수치·필드는 삭제/비노출해야 한다.
5. **운동 공간:** 헬스장 외부 API 검색·주소/위치 검색은 MVP에서 구현하지 않는다. 직접 이름 등록과 보유 기구 저장만 확정되어 있다.
6. **마일스톤:** 첫 운동·누적 20일·첫 도전 완료, 데이터 조회 실패와 미달성 구분. LV 배지 미구현.
7. **가이드 콘텐츠:** 사용권과 동작·주의사항 검수 기록이 없는 35종 안내는 현재 모두 비노출. 실제 검수 전 시안의 사진·문구를 앱 화면 근거로 사용하지 않는다.
8. **기구 기반 추천:** 모든 35개 매핑 행은 승인 전이므로 개발 적용 금지. 운동 목적도 추천 로직에 아직 반영하지 않음.
9. **Wear 연결 상태:** 실제 기기 연결 검증 전 임의의 '연결됨' 상태를 표시하지 않는다. 워치 페이스의 단계 이름 노출은 현재 유지하는 정책.
10. **앱 설정:** 알림의 추가 토글·소리/진동 분리 등 미승인 항목은 임의 추가하지 않는다. 민감한 운동 정보 잠금화면 공개 기본 OFF.
