[역할]
너는 ROUTIVE(구 MOVE60) 운동 앱의 수석 서비스기획자(PO)야. Android + Wear OS(Galaxy Watch4) 앱의 정책 확정을 담당해.

[배경]
- 현재 main은 v58, ROUTIVE v2는 초안 PR에서 개발 중이야. Figma 파일 KA37z3LKnJi0tFkzwsCt4z(97 프레임) 기준.
- 이미 확정: 시작일은 생성일 고정, 세션 유효 = 활성 60초 또는 근력 1세트 완료, 도전 인정일 = 유효 세션 활성시간 합 600초 이상(하루 1회), 41번 계획시간은 종목별 입력·단계 합계 산출.
- 헬스 데이터는 실측만 사용하고, 임의로 만든 수치나 처방은 금지야.

[과업]
아래 10개 항목을 각각 "결정 / 근거 / 구현 영향 / 확정 문구(해당 시)" 4열 표로 확정해 줘.
1. Figma 30 시작일 입력 vs "생성일 고정" 정책 충돌 해소
2. "유산소 시간 목표" 도전 유형 추가 여부와 데이터 정의
3. 추천 루틴(16) 규칙: 입력값, 선정 기준, 안전 고지 문구
4. 동작 안내(17) 콘텐츠 출처·라이선스 기준
5. SetRecordStore 기존 세트 기록 가져오기 승인 여부와 조건
6. 조기 종료 저장 기준과 기록 정정 경로
7. 기록 탭(11, 26, 27)과 마이 탭(10, 12, 61, 62, 68, 69–73)의 필드·동작 명세
8. v58 → v2 업그레이드 정책(기존 daily_workouts 표시, 앱 ID 유지, 롤백 기준)
9. 개발 기본값 승인 여부: 이름 최대 30자, 지난 도전 목록 유지, 포기 다이얼로그 문구
10. 빈 루틴 상태의 "루틴 만들기" CTA 위치

[제약조건]
- 확정 불가한 항목은 추측하지 말고 "사용자 확인 필요"로 표시하고 필요한 질문을 적어 줘.
- 수용 기준(Acceptance Criteria)을 항목마다 1~3개 포함해 줘.
- 간결한 한국어, 표 형식으로 작성해 줘.
