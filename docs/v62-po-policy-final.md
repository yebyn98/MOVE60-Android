## 6. 조기 종료 및 기록 정정
조기 종료
- 활성 60초 이상 또는 근력 완료 세트 1개 이상이면 유효. 미완료 단계가 남은 조기 종료 = `PARTIAL`. 모든 단계가 수행 또는 명시적 생략으로 결정되고 수행 단계가 1개 이상 = `COMPLETED`(생략만으로 자동 `PARTIAL` 금지). 실제 수행 없음 = `NOT_PERFORMED`. 유효 미달은 영구 저장하지 않음. 일시정지·근력 휴식시간은 활성시간에서 제외.
- 문구: "운동을 종료할까요?" / "지금까지 수행한 내용이 기록돼요." / [계속 운동] [운동 종료] / "저장 기준에 도달하지 않아 이번 운동은 기록되지 않아요."

- 주체: 기록 소유자 본인. 기간: 기록이 보존되는 동안 언제든지.

## 충돌·확인 필요 (임의 결정 금지)
1. **칼로리**: 정책은 "전체 화면 숨김"이지만 출시된 v58에는 이미 표시가 있다 — 레거시 상세 도크("오늘 누적 … kcal · 추정", 워치 측정 kcal v57 옵트인), 결과("약 N kcal"), Compose 오늘 누적 kcal, 달력 단계별 kcal. 신규 v2 화면에는 적용하고, **기존 v58 표시를 제거할지는 PO 확인 필요**(제거하면 v58 사용자에게 보이던 기능이 사라짐).
2. **RPE 수정**: 정책은 RPE를 수정 가능으로 두지만 v2 세션 화면에는 RPE 입력이 없어 저장된 값이 없다. 없는 값을 만들지 않고, 저장된 값이 있을 때만 수정 대상으로 한다.
3. **신규 데이터(운동 목적·공간·헬스장·기구)**: Room v6 스키마가 필요한데 이 개발 환경에는 Android SDK가 없어 스키마 파일을 만들 수 없다. 선택지 — (a) CI가 생성한 스키마 아티팩트를 내려받아 정식 Room으로 구현(아티팩트 다운로드 권한 필요), (b) 임시로 버전 있는 설정 저장소(SharedPreferences JSON)로 구현 후 Room 이전. (b)는 이전 부채가 생긴다.
