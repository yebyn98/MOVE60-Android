# 기록 화면 (Figma 11 · 26 · 27) — 1차: 저장된 실제 값 기반

Figma `KA37z3LKnJi0tFkzwsCt4z` — 11 `412:3247` 운동 달력 / 26 `412:3890` 운동 날짜별 기록 / 27 `412:3938` 운동 세션 상세.
참고 상태 프레임: `412:3851`(기록 없음), `1050:7291`(26 · 1세션), `1054:7320`(27 · 사이클 세션), `1297:6698`(27 · P-08 실제 강도 구간) — 이번 슬라이스에서 대조하지 않음.

## 흐름
달력(11) → 선택일 카드 "운동 N회" → `record_day/{date}`(26) → 세션 카드 → `record_session/{sessionId}`(27). 26·27에서도 하단 탭은 기록 탭이 선택된 상태로 표시.

## 구현 원칙
- 읽기 전용: `RecordReader`(`RecordScreens.kt`, `RecordViewModels.kt`)는 DB·SharedPreferences에 쓰지 않는다. DAO에 조회 쿼리 3개만 추가(`sessionDatesBetween`, `sessionsOn`, `sliceSeconds`), 엔티티·스키마 변경 없음.
- 저장된 값만 표시. 이전 버전(`daily_workouts`) 하루 합계는 따로 표시하고 새 세션 시간과 더하지 않는다(C-20261115-04).
- v58 세트 기록은 정책 5(`docs/v59-legacy-set-records.md`)에 따라 연결 가능하면 세션 상세에, 아니면 "이전 버전에서 저장한 기록"으로 따로 표시.
- 읽기 오류는 "불러오지 못했어요 + 다시 불러오기"로 표시(빈 기록으로 위장하지 않음).

## Figma 요소 ↔ 저장 데이터
v2 커밋 경로는 `session_segments`·`planSnapshotJson`을 채우지 않는다(`TimerSessionSync`가 `emptyList()`/`null`로 저장). 따라서 아래 요소는 그리지 않았다.

| 시작 시각 `20:35 시작` | 세션 시작 시각 + 시간대 | 표시 |

### 다음 슬라이스 결정 필요 (PO)
Figma 27 전체를 구현하려면 **세션을 저장할 때 루틴 이름·단계별 시간(구간)을 함께 저장**해야 한다. 새 세션부터만 해당하고 마이그레이션은 필요 없지만, 커밋 경로(멱등·충돌 규칙)가 바뀐다. 칼로리는 별도 산출 정책이 있어야 한다(없는 값은 만들지 않음).

## 사용한 대안 (Figma와 다른 점)
- 아이콘은 기존 화면과 같이 Material 아이콘(`ChevronRight`, `Schedule`, `ExpandLess/More`). Figma의 SVG 아이콘 에셋은 쓰지 않았다.
- 헤더는 기존 `ScreenTopBar`(왼쪽 정렬)를 사용. Figma의 가운데 정렬 헤더와 다르다.
